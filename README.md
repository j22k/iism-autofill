# IISM Form Filler

Free, local, open Chrome extension that autofills the IISM Gulmarg admission form from a saved profile. Never submits. No accounts, no network.

## Start building with Claude Code
```bash
cd IISM-extension
git init
claude
```
Then in Claude Code, run `/plan-task T-001` (you do the manual capture), then `/plan-task T-002`, and continue down `docs/06-backlog.md`.
Loop per task: `/plan-task` → `/tdd` → `/verify` → `/review` → commit.
